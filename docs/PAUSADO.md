# Michael pausado

O desenvolvimento do Michael fica pausado nesta versão:

Michael 2.0 Minimal Stable.

## Motivo

A versão atual já cumpre o objetivo principal:

- produtividade local;
- comandos úteis;
- router seguro;
- baixo atrito;
- sem LLM;
- sem Hermes;
- sem complexidade desnecessária.

A integração com LLM/Hermes foi adiada para evitar distração dos cursos.

## Regra

Não adicionar novas funções sem necessidade real.

Se voltar ao projeto, começar por testes controlados de LLM como fallback de intenção, nunca como executor direto de comandos.
